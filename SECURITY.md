## Security & Privacy Commitment

Workspace.mac is a client-side macOS application connecting to Google services through Apple's native WebKit sandboxing.
- Direct-to-Google communication only.
- No intermediary proxy, analytics, or third-party servers.
- Session cookies, credentials, and cache remain stored exclusively on your local device.

## Reporting a Security Concern

If you believe you have discovered a vulnerability, please reach out via a private GitHub Security Advisory or report it directly via GitHub issues. Vulnerabilities are reviewed and patched promptly.
