# Workspace.mac

> A fast, native macOS desktop client for Google Workspace apps with customizable layouts, standalone app windows, and complete privacy.

## ✨ Features

- **18 Google Workspace Services & Gemini**: Instant access to Gmail, Docs, Sheets, Slides, Drive, Calendar, Meet, Chat, Keep, NotebookLM, Forms, Sites, Contacts, Tasks, Classroom, Google Cloud, and Gemini.
- **Standalone App Windows (New in v1.1.0)**: Detach any app into an independent window with minimal top controls for multi-monitor workflows.
- **Interactive Zoom Controls (New in v1.1.0)**: Dedicated `+` / `-` zoom buttons with standard `Cmd +` / `Cmd -` keyboard shortcuts.
- **Drag-and-Drop Pinning (New in v1.1.0)**: Drag service cards straight into the Pinned Apps section.
- **Direct NotebookLM Access**: Launches straight into your active notebooks dashboard.
- **Privacy & Security First**: Direct connections via native WebKit sandboxing. No background analytics, telemetry, or third-party servers.

## 📥 Installation

Download the latest version from our [Releases page](https://github.com/Charles12214/Workspace.mac-public/releases/latest):

1. **DMG Disk Image**: Open `Workspace.mac-1.1.0.dmg` and drag `Workspace.mac` to `/Applications`.
2. **PKG Installer**: Run `Workspace.mac-1.1.0.pkg` for a guided installation.

*Requires macOS 13.0 (Ventura) or later on Apple Silicon (M1/M2/M3/M4).*
